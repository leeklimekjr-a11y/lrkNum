lrkNum is a set of Python scalar classes that allow for custom arithmetic habavior and inclusion and tracking of additional metadata within scalar instances.

Roadmap
* Fully compatible with Numpy, Pandas, sk-learn, SciPy, Math, and native Python containers and arithmetic operations
* Supports arithmetic clamping at a given value 
* Performatively tuned for  large arrays
* Supports numpy vectorization
* Custom Numpy dtype
* Includes comprehensive set of unit tests to cover all arithmetic operations/functions as well as package-specific tests to ensure compatibility
* Includes a set of benchmark performance tests 
* Custom rounding behavior
